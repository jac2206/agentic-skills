# JAC · SVG Assets

Vectorizaciones aproximadas de los logos raster oficiales suministrados. No son vectores maestros originales.

- `jac-isotipo-dark.svg`: emblema circular sobre fondo oscuro.
- `jac-isotipo-transparent.svg`: variante con fondo exterior transparente.
- `jac-logo-completo.svg`: emblema con JAC.
- `jac-favicon.svg`: versión vectorial reducida.
- `jac-wordmark.svg`: wordmark tipográfico escalable (Montserrat preferida).
- `jac-brand-tokens.css`: colores oficiales.

**Nota:** las vectorizaciones mantienen muchos trazados para reproducir el detalle. Para favicon de 16–32 px conviene una simplificación manual posterior.
